# 体組成管理 設計

作成日: 2026-10-02

## 目的

体重と体脂肪率を日々記録し、推移を読めるようにする。将来は iPhone のヘルスケアから
自動で値が入るようにし、手入力をなくすことを目指す。

## 背景と制約

### ヘルスケア連携はPWAからは不可能

HealthKit は iOS のネイティブAPIで、Web用のAPIもOAuthも存在しない。ホーム画面に
追加した状態でもブラウザのセキュリティ枠内で動くため、権限を持てない。本物の連携には
ネイティブアプリ（Capacitor等でのラップ、App Store審査、Apple Developer Program）が要る。

現実解は **iOSのショートカットのオートメーション**。ショートカットはヘルスケアの値を
読め、Webhookも叩ける。「毎朝8時に体重を取得してGlogに送る」を各自が1回設定すれば、
PWAのままでも自動記録が成立する。本設計はこの道を前提に、今回は手入力を作り、
外部から値を受け取れる形を構造に織り込んでおく。

### 既存の資産

`bodyweight_logs` が既にある。

| 列 | 型 | 備考 |
| --- | --- | --- |
| user_id | uuid | 既定値 `auth.uid()`、`profiles` へのFK |
| recorded_on | date | |
| bodyweight_kg | numeric(4,1) | 20〜300 |

主キーは `(user_id, recorded_on)` で1日1件。RLSは本人のみ全操作可。
チンニング・ディップスの総重量計算がこのテーブルを読んでいる。

## 決定事項

### 記録項目は体重と体脂肪率のみ

家庭用体重計で信頼できるのはこの2つ。入力もグラフも軽く保て、ショートカット連携も
確実に扱える。筋肉量や内臓脂肪レベルは今回入れない。後から列を足せる構造にしておく。

### 既存テーブルを拡張する

`bodyweight_logs` に `body_fat_pct numeric(4,1)`（任意、1〜70%）を追加する。
体重だけの記録も成立させるため NULL を許す。新しいテーブルを作らない理由は、
体重の置き場所が2か所になるとどちらが正か分からなくなるため。自重種目の計算が既に
このテーブルを唯一の出所にしている。

テーブル名が体重寄りのまま残るのは承知のうえで受け入れる。内部名であり、改名の
手間とリスクに見合わない。

### 1日1件を維持する

主キーをそのまま使う。同じ日に入れ直せば上書き。アプリ全体の「1日1回」の考え方とも揃う。
ショートカットが毎朝送っても重複しない。

### グラフは生の点と7日移動平均

体重は食事や水分で日々数百g動く。生の点だけでは増減の向きが読めないため、
7日移動平均の線を主役にする。移動平均は対象日を含む過去7日間の記録の平均とし、
記録のない日は計算に含めない（窓内に1件でもあれば値を出す）。

## 画面

### 新しいタブ「体組成」（`/body`）

下部タブを ホーム／履歴／BIG3 の3つから ホーム／履歴／BIG3／体組成 の4つにする。
毎日見て毎日入れる性質のデータなので、最短で到達できる場所に置く。

構成（上から）:

1. **今日の入力** — 体重と体脂肪率。直近の値を初期表示する。体脂肪率は任意
2. **グラフ** — 生の点と7日移動平均。体重と体脂肪率はタブで切り替える（2軸を重ねると読みにくい）
3. **期間切り替え** — 1ヶ月／3ヶ月／1年
4. **最近の記録** — 一覧。表示範囲はグラフと同じ期間に揃える。タップで修正、
   左スワイプで削除（記録画面と同じ操作）。削除はその日の記録ごと消える

### 既存画面の扱い

- 記録画面（自重種目での体重入力）は**そのまま残す**。その場で必要になるため
- プロフィールの体重入力は新タブへの導線に置き換える。入力場所が2か所になるのを防ぐ
- Markdownエクスポートに体脂肪率を加える

## 次フェーズ: ショートカット連携

体組成の手入力フェーズでは将来拡張としていた連携を、別フェーズで実装した。
現在の契約と認証設計は [Health同期設計](2026-10-02-health-sync-design.md)、
本人向け設定は [Shortcut手順](../../health-sync-shortcut.md) を参照。
POSTは `records` 配列の期間バッチで、既定keep・明示overwriteを扱う。
公開migration/Function適用とiPhone実機確認は承認後の作業で、現時点では未実施。

## テスト

単体:

- 7日移動平均の計算（記録のない日を飛ばす、窓の端、1件だけの場合）
- 期間フィルタ（1ヶ月／3ヶ月／1年の境界）
- 体脂肪率なしの記録が保存・表示できる
- 同じ日の再保存で上書きされる

E2E（モック）:

- 体組成タブで入力 → グラフに反映 → 一覧に出る → 修正できる
- 体脂肪率を空のまま体重だけ記録できる

## やらないこと

- 筋肉量・内臓脂肪レベル・骨量などの追加項目
- 目標体重と達成度（移動平均を優先。必要になったら足す）
- 体組成計メーカーのクラウド連携
- ネイティブアプリ化
