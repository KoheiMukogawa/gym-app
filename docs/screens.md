# Glog 画面一覧

更新日: 2026-10-30。初期設計書の通し番号とは別に、以下を現在の固定IDとして使用する。
要望・不具合は「REC-02 記録入力のダイヤル」のように指定できる。IDは一般の利用者には表示しない。
管理者はヘッダーのメニューの「画面IDを表示」をオンにすると、ログイン後の画面のヘッダーにIDが出る（端末ごとに保存）。AUTH・PUBLIC・LEGALはヘッダーのない画面なので出ない。
「画面IDを表示」をオンにすると、表示中のボタンと操作リンクの右上にもIDが出る。例: `REC-02-BXXXXXXX`。画面内の操作名からIDを決め、同じ名前の操作が複数ある場合は末尾に番号を付ける。文言が変わる操作は `data-button-key` で固定する。一般の利用者には表示しない。
アプリ内の対応表は `src/features/admin/screenIds.ts`。画面を足したら両方を更新する。

## 記録入力と履歴編集の共通ルール

- 種目ごとにセットをまとめ、セット番号・重量×回数・推定1RMを固定した列に表示する。
- 同じダイヤル部品を使う。スクロール・±・直接入力に対応する。
- 1〜10回は通常の推定1RM、11〜30回は参考値。対象外でもRM列を残す。
- 自重種目は記録日の体重と加重から計算する。体重未設定は数値を捏造しない。
- REC-02とHIS-02は下部の入力ドックを取っ手の上下スライドで折りたたみ可能。表示を戻しても入力値は保持する。
- HIS-02は見出しに記録日を表示し、既存セットの編集を維持。カード内の「セットを追加」と下部の「種目を追加」から、種目選択後は同じ下部ドックで入力する。
- セットの切り替えで未保存の値を保持し、保存失敗時は再試行できる。
