# Glog 登録・プロフィール・記録画面

## 公開環境で必要な設定

1. Supabase SQL Editorで `0008_communities.sql`、`0009_onboarding_global_ranking.sql` の順に適用。既に0008が入っている場合も再実行可能。
2. Supabase Authentication設定で新規登録を許可する。2026-10-01時点の公開Auth設定は `disable_signup: true` だったため、アプリのデプロイだけでは登録できない。
3. Site URLに本番URL、Redirect URLsに `https://gym-app-ruddy-nine.vercel.app/profile` を設定。メール確認を有効にする場合は確認メールからの遷移も検証する。

## 動作

- 未ログインでトップを開くと紹介ページ。既存利用者はログイン、初回は名前・選択式SVGアイコン・メール・パスワードで登録する。
- SQLのユーザー作成トリガーでプロフィールを保存。メール確認の有無に対応し、公開ランキングには自動参加しない。
- ヘッダーは大きいGlogロゴとプロフィールアイコン。外側タップ、Escape、画面遷移でメニューが閉じる。
- プロフィール画面の保存はRPCで自分の公開用プロフィールとアカウントプロフィールを同期する。
- Big3は自分／全体／コミュニティを切替。全体は明示的に公開を選んだ人だけを集計し、全履歴や日別推移は公開しない。コミュニティ内共有は従来どおり。
- 記録画面はルート移動中もマウントを保ち、保存処理と入力を継続する。終了時のみ画面状態をリセットする。リロード時は既存のユーザー別・日付別下書きから復元。
- 重量・回数はスクロールと直接入力。重量ホイールは0〜500kgを2.5kg刻み、回数は1〜100回。範囲外や細かい重量は直接入力可能。
- 推定1RMは入力と同時更新。1〜10回が対象。種目の中にセットを昇順で表示する。
- 入力パネルは通常レイアウトに配置し、固定下部ナビを覆わない。

## 今後

体重管理は今回の実装に含めない。追加する場合は日付・ユーザーにひも付く独立した測定テーブルと推移画面を設け、筋トレ記録とは分けて保存する。
