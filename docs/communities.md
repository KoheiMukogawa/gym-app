# 招待制コミュニティ

## 適用

Supabaseプロジェクト `lombbjpiftuqkacasmzg` の SQL Editor で `supabase/migrations/0008_communities.sql` を全選択して実行します。0001〜0007が適用済みであることが前提です。トランザクション内で実行され、再実行も可能です。

更新後、Big3 → コミュニティ → プロフィールを保存 → 作成または招待コードで参加。
SQL未適用の場合は準備中のメッセージが表示され、通常の記録・履歴・自分のBig3は引き続き使えます。

## 共有範囲

参加は明示操作です。表示名・選択式アイコン・ひとこと・Big3推定1RMとその日別推移を同じコミュニティのメンバーに共有します。元のprofilesとは独立した公開用プロフィールなので、メール由来の既存表示名は自動公開しません。

旧SNSの全件閲覧ポリシーを本人限定へ変更します。全トレーニング履歴の共有機能は提供しません。旧フィード／メンバーページのAPIも他人の記録を読み取れなくなります。

コミュニティと所属テーブルは直接アクセス不可。RPCが参加状態を検査して必要な集計のみを返します。招待コードは作成者だけが取得可能で、再発行により以前のコードを無効にできます。退出すると以後の取得が拒否されます（すでに受信した情報の回収はできません）。作成者は削除可能、通常メンバーは退出可能です。

## スコア

自分のBig3と同じ対象種目マッピング／プリセットを使用。1〜10回、正の重量のセットをBrzycki式で1RMに換算し、小数1桁に丸めて各種目の最高値を合算。未来の記録は除外。3種目がそろわない場合は順位なし。

今月の伸びは日本時間の月初前までの最高合計と現在の最高合計との差分。月初前に3種目がそろわない人は比較対象外です。0kgの伸びは有効。同値は同順位（1,1,3）。記録の修正や削除は次の取得に反映されます。自己申告ベースであり競技の公式記録ではありません。

## 検証

- `supabase/tests/0008_communities.sql`: テストDBで全migration適用後に実行。作成再試行、RM／成長計算、11回・未来記録除外、非参加者拒否、RLS、参加再試行、退出、権限、再発行、削除後の記録保持を検査。テストはrollback。
- `tests/e2e/community.spec.ts`: スマホ表示でプロフィール、保存エラー再試行、作成、ランキング取得再試行、同順位、成長比較、プロフィール詳細、招待再発行、参加・退出。
- `npm run test:e2e:mock` で既存の記録・履歴・Big3操作も検証。

実サービスでの複数アカウント動作確認は、SQL適用後に行ってください。
