# iPhoneヘルスケア → Glog 設定手順

## 最初に行うこと

Glogの連携画面は「連携キーを用意 → ショートカットを設定 → 1日分で同期を確認」の順です。連携キーは、以下の手順中の Token（個人トークン）と同じものです。

現在、完成済みショートカットの簡単追加は準備中です。「手動設定の手順を見る」を開くと、送信先URLと以下の作成手順が表示されます。作成済みの方はキーを再発行せず、そのまま使えます。

初回は記録がある日の開始日・終了日を同じ日付にし、既存の記録を保持する設定で実行してください。iPhoneで読み取りを許可した後、Glogの「同期結果を確認」を押すと、同期状態とグラフが更新されます。キーの発行だけでは同期は完了しません。

この手順でiPhoneの「ショートカット」アプリに2本のショートカットを作ります。配布用の署名済みショートカットはありません。アクション名や単位の選択場所はiOSによって少し異なります。実機での実行確認は未実施です。最初は本人が選んだ1日で内容・日付・単位を確認してから過去期間を実行してください。

## 1. 接続と秘密の準備

1. Glogの体組成 → ヘルスケア連携を開き、「連携キーを発行」を押す。送信先URLと新しい連携キーをコピーする。
2. iPhoneのショートカットで「＋」→ 新規ショートカットを作り、名前を「Glog 月送信」にする。以下の2つの「テキスト」アクションを追加し、「変数を設定」でそれぞれ URL と Token にする。URLには送信先URLだけ、Tokenには64桁の個人トークンだけを貼る。
3. Tokenは体組成の書き込み専用です。ショートカットの共有、画面写真、メモ、URL、ログへ含めない。Glogの画面を離れた後は再表示できません。再発行したらこのTokenも差し替える。失効後も取り込んだ記録は残る。
4. 初回のヘルスケア権限ダイアログで「体重」「体脂肪率」の読み取りを許可する。許可がないと0件に見えることがあるので、ヘルスケア → プロフィール → アプリ（またはデータアクセスとデバイス）→ ショートカットで確認する。

## 2. 「Glog 月送信」を作る（JSONを受け取る共通処理）

このショートカットの入力は辞書 { records: 配列, mode: テキスト, period: テキスト } とします。periodは失敗時にどの月か示すためのローカル変数で、サーバーへ送りません。

1. 「辞書の値を取得」を3つ追加。ショートカットの入力から records、mode、period を取得し、変数をそれぞれ Records、Mode、Period に設定する。
2. 「カウント」でRecordsの項目数を数える。「もし」件数が0なら「辞書」で ok = 真偽値true、inserted = 数字0、updated = 数字0、skipped = 数字0 を作り、「停止して出力」でその辞書を返す。空POSTをしない。件数が500を超えたら「アラートを表示」でPeriodと「500日以下に分割」を表示し、「辞書」ok = 真偽値false、error = テキスト「500日以下に分割」を「停止して出力」で返す。
3. 「辞書」を追加。キー records の型を「配列」、値をRecordsにする。キー mode の型を「テキスト」、値をModeにする。ほかのキーを入れない。「変数を設定」でPayloadにする。
4. 「テキスト」でPayloadをJSONテキストに変換する。1ヶ月の31日以下、下記3フィールドだけなら256KiBより十分小さい。大量の別データを追加しない。手動でバッチを広げる場合は最大500日かつJSON本文256KiB以下に分割する。
5. 「URLの内容を取得」を追加。URLはURL変数、方法はPOST。ヘッダに Content-Type = application/json と Authorization = Bearer [Token変数] を入れる（Bearerの後は半角スペース1個）。
6. 「本文を要求」（リクエスト本文）はJSONを選び、recordsを配列Records、modeをテキストModeに設定する。Payloadと同じ2キーにする。数値や配列を「テキスト」型にしない。
7. 返り値を「入力から辞書を取得」で辞書にする。「辞書の値を取得」で inserted、updated、skipped を読む。「もし」どれかのキーが「値がない」なら、「辞書」で ok = 真偽値false、error = テキスト「同期失敗」、period = テキストPeriod を作り「停止して出力」でその辞書を返す。TokenやPayloadをエラー文へ入れない。
8. 「辞書」で ok = 真偽値true、inserted = 数字inserted、updated = 数字updated、skipped = 数字skipped を作り、「停止して出力」でその辞書を返す。テキストに変換せず辞書で返す。

通信・HTTPエラーで「URLの内容を取得」が止まった場合も、その月は成功扱いにしません。呼び出し元の通知に表示された月から再実行します。APIのJSONエラーは400（入力）、401（無効・失効）、413（本文サイズ）、415（Content-Type）、500（内部エラー）。401ならTokenを確認し、必要ならGlogで再発行して差し替える。失敗後は同じ期間をkeepで再送できます。追加・更新・保持の合計が送った日数か確認します。updatedは値が同じ上書きも数えます。

## 3. 「Glog 期間同期」を作る（日ごとの最新値、月ごとの送信）

別の新規ショートカットを作り、名前を「Glog 期間同期」にする。変数名は下記と同じにすると設定しやすくなります。

1. 「入力を要求」を追加し、種類「日付」、質問「開始日」。その出力を「日付を調整」で「日の始まりを取得」し、Startに設定する。同様に質問「終了日」→ 日の始まり → Endに設定する。
2. 「もし」EndがStartより前なら、アラート「終了日は開始日以降」→ ショートカットを停止。Endを「日付を調整」で1日加算し、EndExclusiveに設定する。開始日と終了日の両方を含めるため、上限は終了日の翌日00:00です。
3. 「メニューから選択」で「既存の記録を保持（通常）」と「既存の体重を上書き」を作る。前者は「テキスト」keep → Mode。後者はアラートで体重を書き換えることを確認し、「テキスト」overwrite → Mode。体脂肪率がない日は、overwriteでも既存の体脂肪率を残します。
4. 「日付間の時間を取得」でStartからEndExclusiveまでの日数 → 「数字を丸める」で常に切り上げ → Daysに設定する。夏時間のある地域でも余分な1日を送らないよう、各日のEndExclusiveチェックを下記に置く。
5. Start → Dayに設定。「リスト」アクションの全項目を削除し、空リストをBatchに設定。Dayを「日付をフォーマット」、カスタム yyyy-MM → Monthに設定する。日付のタイムゾーンはiPhoneのローカルのままにし、UTCにしない。
6. 「繰り返す」を追加、回数をDaysにする。以下7〜13をその繰り返しの内側に置く。
7. 「もし」DayがEndExclusiveより前のときだけ8〜12を実行する。Dayを「日付をフォーマット」、カスタム yyyy-MM → ThisMonth。
8. 「もし」ThisMonthがMonthと異なる場合、下記「月を送る」ブロックを実行。その後、空「リスト」→ Batch、「変数を設定」でThisMonth → Month。これで月ごとの最大31日になります。
9. Dayを「日付を調整」で1日加算 → NextDay。Dayを「日付をフォーマット」、カスタム yyyy-MM-dd → DateKey。書式は小文字yyyy（週番号のYYYYにしない）。UTC変換やISO日時の先頭10文字の切り出しはしない。
10. 「ヘルスケアサンプルを検索」を追加。種類「体重」、開始日がDay以降かつNextDayより前、並べ替え「開始日」、順序「新しい順」、制限オン・1件。日付フィルタが「範囲内」しかないiOSではDay〜NextDayで検索して制限をオフにし、検索前に空「リスト」→ Candidatesを設定する。検索結果を「各項目を繰り返す」→「ヘルスケアサンプルの詳細を取得」で開始日→「日付をフォーマット」yyyy-MM-dd→「もし」DateKeyと一致したら「変数に追加」で繰り返し項目をCandidatesへ追加する。繰り返しの後に「リストから項目を取得」でCandidatesの最初の項目を取得する（検索の新しい順を保つ）。境界00:00の別日の測定を含めない。
11. 「もし」体重の結果が「値がある」場合、そのサンプルの「詳細を取得」で「値」を取得し、単位をkgに設定して「入力から数字を取得」→ Weightにする。単位を選べるマジック変数でもkgを指定する。lb表示ならkgへ変換してから数値にする（lb × 0.45359237）。単位つきの文字列をJSONへ入れない。Weightが20未満または300より大きいならアラート「[DateKey] 単位・体重を確認」→ ショートカットを停止。「辞書」で date = テキストDateKey、weight_kg = 数字Weight の2キー → Record。
12. 11の「もし」の内側に、別の「ヘルスケアサンプルを検索」を追加。種類「体脂肪率」、同じDay〜NextDayのローカル日、開始日で新しい順・1件。10と同じ日付境界の確認を行う。結果がある時だけ、値を%で取得 → 数字Fat。「辞書の値を設定」でRecordのbody_fat_pctに数字Fatを入れ、出力辞書をRecordに再設定する。%表示の15.4を15.4のまま送る。単位設定後も端末が0.154の比率で返す場合だけ100倍し、ヘルスケアの表示と一致することを初回1日で確認する。別の日の脂肪率を補完しない。Fatが1未満または70より大きいなら「もし」でDateKeyと「単位・脂肪率を確認」をアラート表示して停止する。体重だけならbody_fat_pctキーを入れない。脂肪率の「もし」を閉じた後、体重がある場合の「もし」の内側に「変数に追加」を置き、RecordをBatchへ追加する。脂肪率がない体重だけの日も追加する。体重なしの日は何も追加しない。
13. 7の「もし」の外、繰り返しの末尾でDayを「日付を調整」で1日加算 → Dayに再設定する。
14. 繰り返しの後にもう一度「月を送る」ブロックを置いて、最後の月を送る。

「月を送る」ブロック（8と14の両方に同じアクションを置く）:
- 「カウント」でBatchの件数。「もし」0より大きい場合のみ次を実行。
- 「通知を表示」で「[Month]を同期中」を表示。通信エラーで止まったとき、最後の通知の月から再送できる。
- 「辞書」を追加。records = 配列Batch、mode = テキストMode、period = テキストMonth。
- 「ショートカットを実行」で「Glog 月送信」を選び、入力をその辞書にする。
- 戻り値を「入力から辞書を取得」。ok、inserted、updated、skippedを「辞書の値を取得」で読み取る。「もし」okが真ではない、または成功3件数のいずれかが「値がない」なら、Monthと「同期失敗」を「アラートを表示」→ 親の「このショートカットを停止」。子からの空出力も成功扱いにしない。
- 成功時だけ「計算」で inserted + updated + skipped を求め、Batchの件数と一致しなければMonthと「件数不一致」をアラート → 停止。一致した時だけ「テキスト」で「[Month] 追加[inserted]日 / 更新[updated]日 / 保持[skipped]日」を作り「通知を表示」。次の月へ進む。

生成される本文の例（同じ日の最新だけ、JSON数値）:
{"records":[{"date":"2023-01-02","weight_kg":70.2,"body_fat_pct":15.4},{"date":"2023-01-03","weight_kg":70.1}],"mode":"keep"}

開始日〜終了日の各日を1回ずつ処理するので、同日重複はありません。毎月31日以下の送信に分かれ、長期間でも500件制限に当たりません。数年分は時間がかかります。iPhoneをロックせずショートカットを前面に置き、必要なら開始・終了を数ヶ月に分けます。再実行のkeepは既存日を変えず、不足日のみ追加します。訂正した測定を反映する時だけoverwriteを選びます。

## 4. 初回確認と毎日の自動実行

1. まず送信前に本人が選んだ1日のRecordを「クイックルック」で端末内だけ確認する。Healthのkg/%とDateKeyが一致しているか確かめたら、確認アクションを外す。トークンは表示しない。
2. 同期後にGlogで「記録を再読み込み」。最終同期の書き込み件数と記録を見る。「全期間」で過去年のグラフ・一覧を確認し、「さらに50件表示」で古い記録へ進む。
3. 「Glog 期間同期」を複製し「Glog 日次同期」にする。最初の2つの日付入力を、現在の日付 → 日の始まり → 3日減算（Start）と、現在の日付 → 日の始まり（End）に置き換える。Modeのメニューは固定テキストkeepに置き換える。残りの月分割・日ループは同じ。
4. ショートカット → オートメーション → ＋ → 時刻（例: 毎日21:00）→ 毎日 → 「すぐに実行」（古いiOSは実行前に尋ねるをオフ）→ 「Glog 日次同期」を実行。初回は手動実行してHealthとURLへの許可を済ませる。端末のロックやHealthのアクセス制限で止まる場合は端末で実行結果を確認し、ロック解除後に再実行する。
5. 最近4日を毎日keepで再送すると遅れて追加された測定を拾えます。4日より古い追加・訂正は期間同期で再送する。連携キーを再発行したら子ショートカット「Glog 月送信」のTokenを差し替える。失効すれば両方の同期は止まる。
